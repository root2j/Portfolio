Simplified, anonymised versions of things I've built at work.

Answers from data, in plain English

People needed answers from data, but getting them meant knowing SQL and where everything lived. I built an AI agent that finds the relevant data, writes the query and runs it behind read-only guardrails, logging every step.

What I took away: clear descriptions of the data did more for accuracy than clever prompts, and safety rules belong outside the model.

Notes that turn into tasks on their own

Action items written down in notes rarely made it into the task tracker. Now an AI step reads the notes, returns tasks in a fixed format, and they're created in the tracker automatically.

What I took away: treating the model as one step in an ordinary program, with a fixed output format, is what made it dependable enough to use every day.

A shared foundation for internal apps

When several apps are built at once, each one solves the same basics its own way. I set up a shared starting point for sign-in, settings and deployment, and one pipeline that builds, checks and releases every app the same way.

What I took away: a shared base only gets used if starting from it is easier than starting from scratch.

How I work
